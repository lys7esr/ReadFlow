# ReadFlow

Hands-free, immersive PDF reading. Upload a PDF, pick a vibe, and let it scroll for you — calm, smooth, and effortless.

Built for students, binge readers, manga lovers, and anyone tired of manually scrolling every few seconds.

A heavily vibe-coded project focused on one thing:
making PDF reading feel passive, cozy, and actually enjoyable.

![Status](https://img.shields.io/badge/status-vibe--coded-6d5dfc)

## 🌐 Live Demo

https://readflow-pdf.netlify.app/

---

## ✨ Features

- 📄 Continuous vertical PDF rendering
- ▶️ Smooth auto-scroll with adjustable speed
- ⏱ 3-second countdown before playback
- 🎨 Four reading vibes:
  - Study
  - Casual
  - Manga
  - Accessibility
- 📱 Mobile-first immersive UI
- 👆 Tap anywhere to pause/resume
- ⌨️ Keyboard shortcuts for desktop
- 💾 Auto-resume reading position & speed
- 🌌 Premium dark theme
- 🔒 100% client-side — PDFs never leave your device

---

## 🧱 Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React + Vite |
| Styling | Tailwind CSS |
| PDF Rendering | react-pdf + PDF.js |
| Routing | React Router |
| Icons | lucide-react |

---

## 🚀 Quick Start

```bash
npm install
cp node_modules/pdfjs-dist/build/pdf.worker.min.mjs public/
npm run dev
```
